# SGP-Pharma Frontend

Interface React locale pour SGP-Pharma.

## Commandes

- `yarn start`: demarre le frontend sur `http://localhost:3000`
- `yarn build`: genere la version production
- `yarn test`: lance les tests frontend

Le frontend appelle le backend local configure dans `.env`:

```env
REACT_APP_BACKEND_URL=http://localhost:8000
```
